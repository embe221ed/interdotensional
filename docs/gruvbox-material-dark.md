# gruvbox-material-dark theme

A custom dark theme that blends **gruvbox-material** syntax colors with **Anthropic Claude's** warm UI palette, rendered through catppuccin.nvim's integration system.

## Design goals

- Match Ghostty's built-in "Gruvbox Material Dark" terminal background (`#282828`)
- Use gruvbox-material's established syntax colors (red, orange, yellow, green, aqua, blue, purple)
- Introduce Claude's warm terracotta/pink tones as accent and UI highlight colors
- Keep warm undertones throughout — no cold grays or blue-blacks
- Leverage catppuccin.nvim's 69 plugin integrations instead of reimplementing highlight groups

## Architecture

The theme uses **catppuccin.nvim as a rendering engine** with full palette overrides. This means:

- Neovim loads catppuccin as the colorscheme plugin
- All 26 catppuccin palette keys are overridden with gruvbox+claude colors
- The `_gruvbox-material.lua` scheme file reads overrides from `vim.g.catppuccin_overrides` (generated by interdotensional — no hardcoded hex values)
- Plugin integrations (telescope, nvim-tree, gitsigns, blink_cmp, etc.) automatically use the custom palette

The scheme file dispatch uses a `scheme` field in `vim.g.colorscheme` to decouple the nvim scheme file name (`_gruvbox-material.lua`) from the vim colorscheme name (`catppuccin`).

## Files

### Interdotensional
- `colorschemes/gruvbox-material-dark.yml` — raw palette (single source of truth)
- `config/themes/gruvbox-material-dark.yml` — tool configs with `$token$` refs

### Neovim
- `lua/ui/schemes/_gruvbox-material.lua` — catppuccin setup with color overrides from `vim.g.catppuccin_overrides`

### Generated
- `output/nvim/globals.lua` — includes `vim.g.catppuccin_overrides` table
- `output/nvim/colors.lua` — semantic color mapper
- `output/colorls/dark_colors.yaml` — file listing colors (hex values)
- `output/tmux/theme.sh` — powerline colors
- `output/zsh/theme.zsh-theme` — prompt colors (ANSI 256)
